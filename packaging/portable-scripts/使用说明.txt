磐垒主动防御 (Bulwark HIPS) — 便携包使用说明
================================================================

■ 就一件事:双击  启动Bulwark.bat

  它会自己判断该做什么,已经做好的步骤直接跳过:

    信任驱动签名证书 → 体检 Secure Boot / HVCI → 开启测试签名
    → 复制 .sys 到 System32\drivers → 注册 Minifilter
    → 加载驱动 → 启动后台服务 → 打开界面

  第一次运行 = 安装 + 启动,会要求重启一次(开测试签名必须重启)。
  重启前它会问你「重启后自动继续吗」,选 Y 就不用再管,登录后自动接着装完。
  以后每次运行 = 只是启动。

  卸载:双击  卸载.bat


■ 需要看状态时

    启动Bulwark.bat -Check

  只体检、不改动任何东西。会把「装到哪一步了、当前是内核前拦截还是
  用户态观测」逐项列出来,每条失败都写明该怎么办。


■ 为什么必须有这一步安装

  Bulwark.sys 是内核模块,不可能从桌面文件夹里直接跑起来。它必须先:

    · 签名证书被本机信任(随包驱动用自签测试证书 CN=BulwarkTestCert)
    · 系统开启测试签名模式(bcdedit /set testsigning on,要重启一次)
    · 文件放进 %SystemRoot%\System32\drivers\
    · 以 Minifilter 语义注册(type=filesys + FltMgr 依赖 +
      Instances\DefaultInstance + Altitude=385201 + Flags=0)

  少了最后那一步的 Instances/Altitude,驱动不会附加到卷,文件和注册表
  回调一个都不会触发 —— 服务能连上内核端口,但什么都拦不到。

  没装会怎样?防护【照样能开】,界面也正常 —— 但事件源静默降级为用户态
  观测,只能事后终止进程,拦不住「行为前」。这种失败从界面上看不出来,
  所以启动脚本每次都会把当前形态明确打出来。


■ 前置条件(不满足则驱动一定加载不了)

  · Secure Boot 必须【关闭】       —— 开着时测试签名完全无效
  · 内存完整性 (HVCI) 必须【关闭】 —— Windows 安全中心 > 设备安全性 > 内核隔离

  这两项脚本会自动检查并告诉你去哪里关。


■ 严重警告

  内核驱动的回调里一旦出错就是直接蓝屏 (BSOD)。首次务必在【带快照的
  测试虚拟机】里验证;要在真机上跑,请先建系统还原点。


■ 便携模式 vs 常驻模式

  默认(便携):启动Bulwark.bat 拉起服务和驱动,关掉界面就一起收摊。
               干净,但关掉就没有防护。

  常驻:  启动Bulwark.bat -InstallService
          把用户态服务注册为开机自启。此后【不要】再用 启动Bulwark.bat
          托管服务(会另起一个实例抢同一条控制管道),直接双击
          bulwark_ui.exe 即可。

  另外 -BootStart 可让驱动开机随系统加载,消除「重启后服务先于驱动
  起来 → 降级用户态 → 勒索漏拦」的防护空窗。


■ 全部可用参数

    启动Bulwark.bat                    默认:缺哪步补哪步,然后启动
    启动Bulwark.bat -Check             只体检,不改动
    启动Bulwark.bat -SetupOnly         只安装,不启动服务和界面
    启动Bulwark.bat -BootStart         驱动改为开机随系统加载
    启动Bulwark.bat -InstallService    服务注册为开机自启(常驻)
    卸载.bat                           卸驱动 + 删服务 + 删 .sys
    卸载.bat -RemoveCert               额外移除测试证书
    卸载.bat -DisableTestSigning       额外关掉测试签名(需重启)
    卸载.bat -All                      以上全做

■ 卸载得干净

  这是正经安全工具,始终保留用户自主卸载的通路,不存在「装上就删不掉」。
  卸载.bat 单独放在外面、不藏在参数后面,就是这个原因。
  规则/日志/隔离区在 %ProgramData%\Bulwark,需要的话手动删该目录。


■ 数据与日志位置

  %ProgramData%\Bulwark\
    bootstrap-status.txt   上次自举的人类可读记录(起不来时先看这个)
    规则 / 日志 / 隔离区

  内核日志:DebugView,勾选 Capture Kernel。
