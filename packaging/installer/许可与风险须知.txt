磐垒主动防御 (Bulwark HIPS) —— 安装前必读
================================================================

这不是一份法律条文,是一份风险告知。请读完再点「我同意」。


一、这个软件会做什么

  它是主机入侵防御系统 (HIPS),类别上与杀毒/EDR 同类。它会:

    · 安装并加载一个【内核驱动】(文件系统微过滤器,altitude 385201);
    · 注册一个以 SYSTEM 身份开机自启的后台服务;
    · 监控进程创建、远程线程注入、模块加载、文件写入/删除、注册表写入、
      网络外联等敏感行为,并在必要时【在行为发生之前】阻断它;
    · 把自己的安装目录、数据目录与服务注册项纳入内核自我保护,防止被恶意
      软件卸载或加密。


二、内核驱动的风险,必须说清楚

  内核代码里的任何一个错误都不是「报个异常」,而是【直接蓝屏 (BSOD)】。

  本产品的驱动带自签测试证书,不经过微软 WHQL 认证,也没有经过商业杀毒厂商
  那种规模的兼容性测试矩阵。

  因此:
    · 首次安装请【优先在带快照的虚拟机或测试机上】进行;
    · 要在日常使用的真机上安装,请先建立系统还原点;
    · 如果这台机器承载着不可中断的工作,请不要现在安装。


三、驱动需要「测试签名模式」

  64 位 Windows 的内核代码签名策略要求内核模块带受认可的签名,自签证书不满足。
  唯一的例外是系统处于测试签名模式(bcdedit /set testsigning on)。

    · 目标机已处于测试签名模式 -> 安装程序会自动加载驱动,拿到完整形态;
    · 未处于测试签名模式       -> 驱动仍会部署并注册好,但【不加载】。
      防护照样开启,只是降级为用户态强制:能事后处置,拦不住「行为发生之前」。
      以后任何时候开启测试签名并重启,后台服务会自动把驱动加载上来。

  开启测试签名模式的代价:桌面右下角出现「测试模式」水印;这台机器此后也会
  允许加载【其他】自签名的内核驱动,这本身降低了系统的签名门槛。

  另外两项会让测试签名彻底失效,必须自行关闭:
    · Secure Boot(在 BIOS/UEFI 里关)
    · 内存完整性 HVCI(Windows 安全中心 > 设备安全性 > 内核隔离)


四、安装程序会改动这台机器的哪些地方

  <安装目录>\                                 程序文件(默认 C:\Program Files\Bulwark)
  %SystemRoot%\System32\drivers\Bulwark.sys   内核驱动
  服务 Bulwark                                内核微过滤器
  服务 BulwarkService                         用户态服务,以 SYSTEM 开机自启
  HKLM\SOFTWARE\Bulwark                       安装痕迹(卸载据此回滚)
  HKCU\...\CurrentVersion\Run\Bulwark         界面首次运行时写的登录自启
  %ProgramData%\Bulwark\                      规则 / 日志 / 隔离区
  「受信任的根证书颁发机构」+「受信任的发布者」  BulwarkTestCert

  最后那一项要特别说明:它是【机器全局的信任变更】—— 往受信任的根里加一张自签
  证书,意味着这台机器此后会信任由这张证书签发的任何东西。所以安装程序只在
  【真的要加载驱动】时才导入它,并且记一笔痕迹,卸载时原样移除;不是本产品导入
  的就绝不去删。


五、卸载

  这是正经安全工具,始终保留用户自主卸载的通路,不存在「装上就删不掉」。

    开始菜单 > 磐垒主动防御 > 卸载
    或:设置 > 应用 > 已安装的应用 > 磐垒主动防御 > 卸载

  卸载会停服务、卸驱动、删两个服务注册、删 System32 里的 .sys、移除本产品导入的
  证书、关闭本产品开启的测试签名、清掉各用户的登录自启项,然后复查一遍并如实
  列出残留(通常是「文件还被内核占着」,重启后再跑一次即可清干净)。

  数据目录(规则、审计日志、隔离区里的真实样本)默认【保留】,卸载时会单独问
  一句 —— 那些数据删掉不可恢复。


六、隐私与联网

  · 本包不含任何情报源 API 密钥,云查默认经中央信誉服务器按文件哈希查询;
  · 上传文件到云端扫描、以及把本地查到的结论回传共享,都是【默认关闭】的开关,
    在界面里可以逐项查看和开关;
  · 「收集诊断日志」会自动脱敏:服务器端点、所有 API 密钥、Bearer 令牌、
    Windows 用户名都会被替换掉;隔离区里的样本内容刻意不打包(那是真实恶意
    样本,打包既会被别的杀软拦下,也等于在传播样本)。


七、无担保

  本软件按「现状」提供,不作任何明示或默示的担保,包括但不限于适销性、
  特定用途适用性。使用本软件造成的系统不稳定、蓝屏、数据丢失或业务中断,
  由使用者自行承担。

  你已被告知:这是一个会在内核里运行代码的安全产品,请在能承受故障的机器上
  先行验证。
